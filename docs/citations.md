# Citations

A citation is a database relationship, not a string invented by the model.

Each retrieved source gets a temporary context label such as `C3`. The label maps to a real `document_chunks.id`, document ID, document title and source page. The LLM may reference `[C3]`; DocMind resolves it through that map and stores a `MessageCitation`.

Unknown labels are stripped. A response that had retrieved sources but emitted no valid citation is visibly flagged as not fully grounded.

Deep links use document/page/chunk parameters so the web reader can navigate to the correct page and, where bounding-box metadata is available, highlight the source excerpt.

Page numbers originate in parsing/OCR and are never generated by the LLM.
